VRT は、モックに描かれたデータ1件の見た目しか見ていない（`docs/mock-replica.md`）。
このスキルは、VRT が見ていないものを受け持つテストを作る。**実装は書かない。**

## 前提
- `docs/mock-spec.md` があり、人間が「未定義」を埋めている。埋まっていなければ止めて質問する
- データの取得口が差し替えられる。差し替えられないなら、差し替え口を作る変更を先に提案する

## 作るもの
1. **表示ルールの単体テスト**：`docs/mock-spec.md` の表示ルールごとに、モック上の例と境界値（0、空、同じ日、うるう年、上限、未知の値）
2. **結合テスト（データ差し替え）**：fixtures とは別の、手で作ったデータで描画する
   - データには必ず入れる：HTML を含む値、未知の状態、0件、同じ日の期間、担当者が先頭にいない行、同名、モックに無い状態値
   - 画面ごとに、**すべての項目**（一覧の全セル、詳細の全項目、title、h1、件数）を、**手で書いた期待値の表と完全一致**で比べる
   - 期待値を、実装と同じ整形関数で組み立てない
   - fixtures の値が画面に出てこないことも確かめる
   - 存在しない ID（0、負、範囲外）、不正な ID
3. **E2E**：`docs/mock-spec.md` の画面遷移とフォームを、実ブラウザでたどる。各画面で console error が 0 件であること
4. **VRT**：`vrt.json` の全画面が check に入っていること

## 仕上げ
- `./scripts/check.sh` が、**まだ実装がない状態で赤くなる**ことを確かめる（最初から緑なら、評価関数が何も見ていない）
- 実装後、`/mutate` を別の文脈で回し、生き残りがあればテストを足す
