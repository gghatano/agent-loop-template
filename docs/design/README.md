# design

人間が読む設計書。**ここが正。** 何を作るか、なぜそうするかを書く。
人間が直接書くか、人間が議論に書いた結論を AI が清書する（`docs/README.md` のルール）。
文章・図・画面の説明でよい。AI が読む形式（表・ID）に寄せる必要はない。それは `spec/` がやる。

- 見出しは、spec から `#見出し` で参照される。見出しの名前を変えると、参照している spec が赤くなる（それでよい。参照を直す）
- 実装の細部（関数名、ファイル構成）は書かない。コードを読めばわかる
- 書けない・決まらないことは `discussions/` に出す
